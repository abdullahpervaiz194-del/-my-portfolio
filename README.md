## 🌟 Key Features

### 1. Interactive Technical Playgrounds
- **Playable DSA Algorithm Visualizer**:
  - Live sorting algorithm animations (**Bubble Sort, Selection Sort, Insertion Sort**) built using asynchronous JavaScript generators.
  - Step-by-step stepping, play/pause controls, speed slider (30ms–300ms), and time/space complexity analysis ($O(N \log N)$ vs $O(N^2)$).
- **Interactive Developer CLI Terminal**:
  - In-browser terminal emulator supporting command history (`↑` / `↓`), tab autocomplete, and commands (`help`, `whoami`, `skills`, `projects`, `dsa`, `matrix`, `contact`, `sudo hire`, `clear`).
- **Live API Integration Sandbox**:
  - Interactive REST API explorer with configurable endpoints, HTTP methods (`GET` / `POST`), custom JSON payloads, headers inspector, and latency tracking in milliseconds.
- **Skills Matrix with "Code Peek"**:
  - Clickable skill cards revealing syntax-highlighted code samples for C++ MinHeap, Python AI Chatbot service, TypeScript generic contracts, Angular standalone components, and SQL analytical queries.

### 2. Featured Projects Showcase
1. **[OmniConvertor](https://omniconvertor-lime.vercel.app/) — Multi-Format Client-Side Converter**:
   - *A modern, privacy-first, client-side web application for converting images, documents, audio, and video directly inside your web browser with zero server uploads.*
   - Features bidirectional PDF to IMG and IMG to PDF conversions, plus integrated **Firebase Database** for conversion preferences and analytics.
2. **Intelligent Python AI Chatbot with API Integration**:
   - Context-aware AI chatbot created through Python featuring asynchronous REST API integration, multi-turn conversation memory, prompt engineering, and rate-limiting fallbacks.
3. **Website Notes — Manifest V3 Chrome Extension**:
   - *Website Notes is a Manifest V3 Chrome extension that stores page-associated notes locally with chrome.storage.local. URL fragments are removed before notes are associated with a page, so different sections of the same article share one note list.*
4. **High-Throughput In-Memory Key-Value Store**:
   - Standalone C++17 memory cache applying custom hash tables, doubly-linked lists for $O(1)$ LRU eviction, and disk snapshotting.
### 3. Sensory & Visual Polish
- **Interactive Particle Constellation Canvas**: Physical 60fps particle mesh responding dynamically to mouse proximity and movement.
- **Web Audio API Sound Effects**: Synthesized futuristic audio feedback (can be toggled in the navigation bar).
- **Cyber-Grid Glassmorphism**: Clean dark-mode aesthetics (`#090d16`), glowing accents, and responsive layout.
